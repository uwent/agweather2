# Changes and announcements

What we have announced about AgWeather: changes to the API, the models and the data sources, outages and delays, and other news, newest first. The same entries appear on the [changelog page](/changelog) and in its [Atom feed](/changelog.atom), which a feed reader can follow.

Each entry gives its date, its kind (`api`, `model`, `data`, `outage` or `announcement`), a title and its text, written in Markdown. An entry about one model or one endpoint names it in `model` or `endpoint`. While `banner_until` is in the future, the website shows the entry as a notice at the top of its pages.

The API changes only by addition, so most of its changes need nothing from you. We announce any change that could affect your code here well before it takes effect.
