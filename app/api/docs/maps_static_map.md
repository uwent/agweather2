# Map image

A finished map of a layer as a PNG image, with county and state boundaries, a title, the date, a legend and a credit line, ready to place in a web page, newsletter or report.

Without a date, the map shows the latest day, so a link such as `/api/v2/maps/dd_modified_50_86.png` always shows the current growing degree day map. `days=7&stat=sum` shows the past week's total, for example of rain. The layer's settings are the same parameters as for `/grids/{layer}`.
