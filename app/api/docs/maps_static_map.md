# Map image

A finished map of a layer as a PNG image, ready to place in a web page, newsletter or report. It has county and state boundaries, a title naming what is mapped (such as "Precipitation, cumulative total" or "Growing degree days, single sine 50–86 °F, cumulative total"), the dates below it (an hour in Central time, with UTC beside it) with how many days or hours a combined map covers, such as "Jun 1 – Aug 31, 2026 (92 days)", a legend, and a caption giving the data sources and, where any days or hours were estimated or missing, the most at any location.

Without a date, the map shows the latest day, so a link such as `/api/v2/maps/dd_modified_50_86.png` always shows the current growing degree day map. With `stat` and no start date, the map combines the days from January 1, so `/api/v2/maps/degree_days.png?dd=sine_50_86&stat=sum` is this season's degree days by single sine 50–86 °F. For degree days, `biofix` starts the total on another day (`biofix=04-15`). `days=7&stat=sum` shows the past week's total, for example of rain. The layer's settings are the same parameters as for `/grids/{layer}`.
