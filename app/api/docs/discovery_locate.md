# A location

What the service knows about a location: the grid cell that contains it (its center and corners), whether it is inside the area the service covers, its time zone, county and state, and the typical early, middle and late planting dates of each crop there.

Results for a location are read from the cell that contains it, so the values describe an area of about 2.5 by 2.5 km (1.6 by 1.6 mi), not the exact point.
