# AgWeather v2

Hourly gridded weather, degree-day, disease and insect models, maps and a public API for agriculture in the Upper Midwest, from the University of Wisconsin–Madison. It replaces the AgWeather API, the AgWeather website, VDIFN and the Crop Risk Tool.

Under construction for the 2027 season. See [PLAN.md](PLAN.md) for the architecture and phases.
